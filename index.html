02 / The concept

Cloud Computing

Cloud computing allows people to use computing resources over a network when they need them. These resources include servers, storage, networking, and software. A provider operates the underlying infrastructure, while customers manage the parts included in their chosen service model. In this project, a managed hosting platform stores the files for my static website and serves them to visitors. My browser can open the local files during development, but other people use the deployed HTTPS address. This separates my development computer from the system delivering the website. When I change the local files, I must publish the updated version before visitors can receive those changes.

03 / The service models

Cloud Services

IaaS

Infrastructure as a Service

Provides fundamental resources such as virtual machines, storage, and networking. The customer manages the operating system and deployed applications, while the provider operates the underlying infrastructure.

Example: Amazon EC2

PaaS

Platform as a Service

Provides a managed environment for deploying applications. Developers manage their application code and settings, while the provider manages the operating system and underlying platform infrastructure.

Example: Google App Engine

SaaS

Software as a Service

Provides a complete application accessed over a network. Users work with the application and available settings while the provider operates the software and its underlying infrastructure.

Example: Google Docs
